# Jackson Yap – Portfolio Website

Static site (HTML, CSS, JS). No build step, no dependencies.

## Files
- `index.html` – all content, plus schema.org data for search and AI engines
- `styles.css` – design (light and dark themes)
- `script.js` – theme toggle, pop-ups, nav highlighting
- `assets/profile.jpg` – profile photo
- `assets/linkedin.png` – LinkedIn logo
- `assets/logos/` – company and school logos

## Host on GitHub Pages
1. Create a repository (for a root URL, name it `<username>.github.io`).
2. Upload everything in this folder, keeping the `assets/` folders as they are.
3. Settings → Pages → Deploy from a branch → `main` and `/ (root)` → Save.
4. The site goes live at `https://<username>.github.io/` (or `/<repo>/`) in a minute or two.
